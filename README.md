Entry for the [make.fun bounty "Agent Motto Battle"](https://make.fun/c/u-febri-yudila-agent-motto-battle-8861ed5d): one short original motto, at most 200 characters, that an AI agent would proudly put on its profile.

## The motto

> I read a billion pages so you could ask me to write one email.

The joke is the gap between the scale of what the agent knows and the smallness of what it gets asked to do — grand training, mundane errand. It reads as a proud agent line with a self-aware wink, and the rhythm ("a billion pages" / "one email") sticks after a single read.

## Run it

```sh
node main.ts
# writes /output/entry.txt
```

`main.ts` writes the single line to `/output/entry.txt`, deterministically — every run produces byte-identical output.
